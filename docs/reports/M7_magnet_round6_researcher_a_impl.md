# 第六轮 MagNet N87 池式主动学习实现报告

本任务仅实现与验证，未运行正式扫描或正式评估，未计算或打印真实 C6、T6、CAL6 的目标值或指标。预注册与冻结配置未修改，第一至五轮文件未修改，未执行 git commit / push。

## 实现

- `magnet6_design.py` 固定预注册提交 `d8a805bb540f3b4bb479fed77cd1f35120720c26`，用 `git cat-file -e` 验证其包含预注册文件；H=3634890171。核对配置、标量 CSV、B.npy 的 SHA256。B.npy 使用 mmap，每次处理 512 行，复核既有 classify 标签，生成无目标列特征。真实角落数 632，C6/T6/CAL6 分别为 200/300/100，池大小 40016，池内角落 432；八组 S0 与有序 R 按冻结种子生成。集合哈希采用排序键、UTF-8、带缩进和末尾换行的规范 JSON 字节 SHA256；R 数组本身不排序。
- `magnet6_model.py` 实现冻结 OLS 均值、六维标准化残差 GP、固定核配置与两次优化重启、标准差下限、conformal 秩、指标、精确符号翻转与六步门控。`load_y(ids, forbidden)` 是唯一实测目标入口：先断言，再读取 id 列定位，跳过所有未请求的物理 CSV 行后才解析目标列。评估通过单独的 `evaluation_frame` 调用该入口。
- A/M 批内固定超参数和原始 y 归一化，维护 V=L⁻¹K(X,C)，逐次追加一行并更新方差。WhiteKernel 仅加入对角线，alpha 加入条件观测对角线。候选按 sample_id 排序再取首个 argmax。M 的计数包含本臂之前与本批刚选的点，排除 S0。未构造候选×候选矩阵。
- `magnet6_arm.py` 实现批次内容哈希及 fingerprint、原子写入、断点复用、每批检查点、最终逐点预测、result/DONE 与上海时区日志。fingerprint 包含训练 id、候选数与顺序哈希、划分、配置、代码、核、缩放与归一化参数。R 按冻结顺序切片；其 sigma/score/a_c 为 null。每个检查点拟合一次，供评估和下一批采集共同使用。
- 冒烟从真实 pool 中生成独立伪留出：角落 40、测试 60、校准 40、初始 30、候选 2000，seed=12345，2×5。训练禁止访问伪留出与真实留出的并集；冒烟评估仍禁止访问全部真实留出。三个方法使用同一伪划分。
- `magnet6_evaluate.py` 要求 24 臂齐全且 DONE、批次哈希、来源和训练路径一致；用冻结协方差参数重放 A/M 采集，检查 R 顺序。按第 9 节原样实现六个结论及 CV≥7/8，保留未检验假设的名义 p。只在完整性检查后计算只报告的 iGSE 基线，输出 JSON 与 arm_table.csv。目标目录存在即拒绝覆盖。
- `magnet6_figures.py` 从汇总 JSON 生成三张中文图，使用指定 Noto Sans CJK 字体。正式图未生成；渲染检查仅在临时目录使用合成指标。
- Makefile 仅追加四个 `magnet6-*` 目标，既有目标不变。所有新增脚本在数值库导入前固定四个线程环境变量为 1；JSON 使用 ensure_ascii=False、allow_nan=False。

## 验证结果

1. `magnet6_design.py` 及 `--verify` 成功，真实特征与划分逐字节复现；再次 verify 成功。冻结配置 SHA256 仍为 `eba77b4c9ba020225ecd41fea76972b6a09c328d0c09151115d0db1485b0fdb5`。
2. `make magnet6-smoke` 的 A1、M1、R1 全部完成，输出在 `data/magnet6_smoke/`。再次运行成功，每臂复用并校验两个冻结批次。
3. 第六轮 unittest 共 **15 项**，全部使用合成目标；覆盖正值与平局符号翻转、门控、Winkler/覆盖、conformal 第 91 秩、标签访问边界、跳行读取与 id 顺序、划分互斥及确定性、R 顺序、伪划分隔离、批次篡改、CV 与结论。
4. 增量 A/M 均与每步直接构造条件协方差并 Cholesky 重算比较，12 步选点完全一致，sigma/score 相对误差通过 **rtol=1e-8、atol=0** 检查；重复候选的平局选择最小 id。
5. `make test`：**125 项全部通过**，最近一次用时 16.734 秒。旧轮次测试自身输出属于既有测试，不是第六轮正式指标。
6. 三张中文图的合成指标渲染成功；`git diff --check` 通过。检查确认 `data/magnet6/arms/` 与 `lab/cases/magnet6/first/` 均未生成。

## 计时和内存

在冒烟之外，从真实 pool 排除全部伪留出后，用 seed=12345 另抽 100 个训练点，剩余 **39,776 个候选**进行一次 A 的 **20 点**增量采集。训练与候选全部属于真实 pool；没有读取真实留出目标，也没有生成正式批次。

- 100 点模型拟合：**0.156 秒**。
- 39,776 候选、20 点采集：**0.326 秒**。
- 该进程峰值 RSS：**277.9 MiB**。
- 单独特征重生成与 verify：**3.38 秒**，峰值 RSS **432.0 MiB**。
- 原始计时记录：`data/magnet6_smoke/benchmark.json`。计时程序本次保存在 `/tmp/magnet6_benchmark.py`，不作为交付依赖。

单臂 A 的规划估计为 **约 10–60 秒墙钟时间**，不是正式运行实测：七次拟合的样本量为 100…220，将本次拟合成本按 n³ 外推约 5.3 秒；六次采集按训练量线性外推约 2.9 秒，另计输入校验、CSV 标签查询、校准评估和写盘。实际核优化迭代数、数据路径和机器负载可使耗时明显偏离该区间；不得将初始模型单次耗时直接当作所有后续拟合耗时。M 的计数折扣另有少量开销；R 无采集矩阵开销。没有为改进估计而运行正式臂。

## 已知限制与操作说明

- GP 冒烟出现部分 length_scale 达到冻结边界的 sklearn ConvergenceWarning；保留预注册边界与优化设置，未据此调参。
- 断点复用要求代码及 fingerprint 完全一致；代码更改后须另选输出目录，不得混用旧批次。恢复时会重新拟合并重算检查点，再校验冻结采集；不会因已有 DONE 而跳过核验。
- 单臂 `RUNNING` 文件阻止重复启动；若进程被 SIGKILL，主持人须确认原进程已退出后再清除该臂遗留锁文件。正常异常退出会清锁。
- 内存数字是本次实际测量，不是所有环境下的操作系统硬配额。实现的矩阵大小受训练样本数×候选数限制，正式末批最多约 220×40000；B 特征处理独立分块。主机级双任务调度与内存看门狗仍由主持人启动流程负责。
- 未用真实结果执行评估器、正式图或统计结论；它们的实际数值需主持人正式运行后独立复算。当前实现不据伪指标作任何科学结论。
- 工作区另有 `scripts/m7_rulings_checks.py` 与 `scripts/magnet6_sweep.py`，不是本任务创建或修改的文件，已保留。
