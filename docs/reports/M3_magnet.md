# M3：MagNet N87 数据管道与 iGSE 基线

## 数据卡摘要

实际使用预训练 N87 子集：40616 条单周期波形，每条 1024 点。ZIP 长度与全部 CRC 校验通过，SHA256 为 `d7c3703295dc113527702cd2420b3334c8eb302c347ecc8ae425b666ce6915ff`。详见 [数据卡](../../lab/cases/magnet/data_card.md)。
温度为 25 ℃、50 ℃、70 ℃、90 ℃；频率、磁通密度幅值及损耗范围均由实际 CSV 统计，见数据卡。
已亲自打开 [官网](https://www.princeton.edu/~minjie/magnet.html)、[软件许可](https://raw.githubusercontent.com/PrincetonUniversity/magnet/main/LICENSE)、[挑战许可](https://raw.githubusercontent.com/minjiechen/magnetchallenge-1/main/LICENSE)、[README](https://raw.githubusercontent.com/minjiechen/magnetchallenge-1/main/README.md) 和 [手册](https://raw.githubusercontent.com/minjiechen/magnetchallenge-1/main/docs/handbook.pdf)。未找到明确的数据许可；代码 MIT 不可直接视为测量数据 MIT。官网已核实完整原始库材料数为 15，预训练包材料数为 10；官网没有给出总样本数，不引用未经核实的全库总数。
没有波形标签。B-only 固定规则得到：正弦 1426 条；三角类 33086 条；梯形 6104 条。规则与逐条抽检在数据卡中；三角类包含多段斜率波形。

## 拟合和积分

按样本原始行序，用 numpy default_rng 固定种子 20261003 对全部正弦 ID 做随机排列，取前一半 713 条训练，其余正弦留出。只在训练正弦中按温度分别拟合 log P = log k + α log f + β log B̂；未对测试集重拟合、调参。
评估总数 39903，其中正弦 713，全部非正弦 39190；预测 CSV 同时保留 train/eval 标签，统计与散点图只读 eval。
B̂ 为峰峰值的一半；f 使用 Hz，B 使用 T，P 使用 W/m³，k 的数值依赖这些单位。每个温度一组参数：

| 温度 ℃ | 训练正弦数 | k | α | β | log 空间 RMSE |
|---|---|---|---|---|---|
| 25 | 165 | 10.27930741 | 1.366345023 | 2.585621173 | 0.101328 |
| 50 | 182 | 0.762327594 | 1.556446562 | 2.587791003 | 0.138437 |
| 70 | 183 | 0.09722931297 | 1.719618854 | 2.609534786 | 0.184470 |
| 90 | 183 | 0.00392010164 | 1.976349369 | 2.603857953 | 0.240633 |

$k_i = k / [(2\pi)^{\alpha-1} 2^{\beta-\alpha} \int_0^{2\pi}|\cos\theta|^\alpha d\theta]$，
$P_{iGSE}=k_i(\Delta B)^{\beta-\alpha}\,T^{-1}\int_0^T|dB/dt|^\alpha dt$，$\Delta B=\max B-\min B$。
余弦积分以 Beta 函数解析求值；B 的周期前向差分包含末点到首点的闭合边，dt = 1/(fN)。在每条线性段上准确积分，所以离散计算为差分斜率绝对值的 α 次幂均值。不平滑 B，不做正弦专用导数替代。

## 与公开文献的核实对比

Venkatachalam、Sullivan、Abdallah、Tacca 的 [原论文](https://www.wcmagnetics.com/wp-content/uploads/2015/02/prediction.pdf) 已打开；[Crossref 注册记录](https://api.crossref.org/works/10.1109/CIPE.2002.1196712) 核实 DOI 为 **10.1109/CIPE.2002.1196712**，题名为 Accurate prediction of ferrite core loss with nonsinusoidal waveforms using only Steinmetz parameters，会议为 IEEE Workshop on Computers in Power Electronics，论文首页标注 COMPEL 2002。
本实现与原论文式 (9)/(10) 的峰峰值 iGSE 及正弦归一化相同；周期 PWL 积分对应式 (13)。原论文还递归分解主/次回线并按所占时间加权；本任务仅用全局 ΔB，未实现该分解。
原文实验使用 3C85 MnZn 环形磁芯，本案例是 MagNet N87，且数据划分、参数拟合范围和误差统计不同。因此不把原论文的性能描述当作 N87 的预期误差，也不声称复现其材料实验结果。
[挑战 README](https://raw.githubusercontent.com/minjiechen/magnetchallenge-1/main/README.md) 描述相对误差和 p95 评价，但其公开比赛表使用另一个验证集及参赛者模型，不能与本任务训练/留出划分直接排榜。本报告仅给出本机实际 iGSE 结果。

## 验证、重跑与证据

`make magnet` 依次通过公共 lab.repro CLI 记录 fetch 校验与 iGSE、绘图、export-case、evidence check。已有 N87 文件在长度及外/内 CRC 全部通过时不再下载；仍会重新核实远端 ETag 和本地完整性。`igse_metrics.json` 为扁平键；录证用副本展开点分键，避免数字检查器把扁平键误当层级路径。
解析正弦与 Steinmetz 的相对误差测试阈值 <1e-3、三角闭式解、分组统计、已知参数恢复及波形规则均有测试。D-02 右图仅样本外，D-05 运行数据缺失/不完整会 skipUnless；划分清单和合成 make_split 测试无需 data/dclink。
预测 CSV 实际字节数 4707137，小于 5 MB，按任务要求存入 lab/cases/magnet；原始测量 B/H CSV 未入库。
实际 make test：75 项，全部通过；make surrogate 重跑通过且与首次入库 surrogate_metrics.json 完全相等。隔离测试在 DC-link 数据缺失及空 JSON 不完整两种状态各运行 7 项，各跳过 2 项运行数据测试，其余通过。
初次成功下载录证耗时 55.065 s，峰值 RSS 49.008 MiB；最近 fetch 校验 8.111 s / 29.926 MiB；最终 iGSE（含 H 形状校验）22.365 s / 477.285 MiB。BLAS/OMP/NumExpr 线程固定为 1；未安装新包。
新增 fetch 测试模拟中断，验证从已有压缩前缀续传、已有完整 ZIP 不下载、完整但损坏的 ZIP 重新获取；测试仅用内存合成 ZIP，不依赖网络或测量数据。
案例见 `cases/magnet_igse/`，中文 report 与 claims 的数字均引用真实运行指标，包含脚本、清单、图及报告的哈希快照。

## 局限性

仅一个材料的预训练子集；不覆盖 MagNet 原始全库。无官方波形标签；多段斜率合并到三角类，随机形状抽检和边界检查不构成独立分类真值。
固定幂律在每个温度内跨频率/幅值拟合，忽略局部参数变化。全局峰峰值版本不处理次回线，数值微分会放大测量噪声。只有离散测量温度的参数，不对中间温度插值。
正弦随机留出仍与训练来自同一测量流程，不是跨设备或跨材料泛化；非正弦完全未用于参数拟合。记录的脚本运行资源为过程树 RSS，并不能替代测量仪器不确定度分析。数据使用授权仍未明确。
