# M4 DC-link 第三轮：实现与冒烟报告

本阶段完成实现、冻结输入设计、配置与隔离冒烟；未运行正式 420 例扫描，未生成正式评估结论或导出证据案例。未 commit/push/checkout/reset。

## 实现

- 依预注册顺序使用单一设计 RNG 生成 LHS；E-dt3 仍使用明确规定的四维 LHS，覆盖死区维为常数。设计与划分只读第二轮 case_id/group，不读目标。文件及划分 SHA256 入库，重复生成仅核对，拒绝覆盖。
- M2 直接复用第二轮 reviewer_b_features、gp_fit、normalized_quantile、interval_metrics；训练集内标准化与线性最小二乘保持一致。每批重新优化残差 GP，批内用 Cholesky 扩展精确条件化，固定核与原始 y 归一化常数，预测方差包含 WhiteKernel。
- 采集先以 usecols 读取标识信息，再以 skiprows 跳过非训练行后解析目标；显式断言禁止校准、测试、角落、dt3、随机臂和补充集目标进入采集。批次首次结果不可覆盖，恢复时核对训练与候选哈希。
- 扫描最多四进程、每进程单线程；逐次尝试 fsync 日志，完成案例跳过，失败原参数重试一次，不替换。崩溃残缺日志仅截断最后未完成行；文件锁禁止同目录重复启动。失败点不进入后续拟合，正式评估要求完整数据。
- 双臂 M0/M1/M2，共用第 55 顺序统计量校准；扁平计数、宽度、C/P 与 Winkler/Wilcoxon 指标，第一次评估原子封存并保存输入及产物哈希。补充集分别与合并报告。
- 十万次均匀秩模拟共享校准集，报告三个覆盖门限的联合误杀率。可交换性没有规定宽度分布，因此明确不将覆盖秩模拟冒称为含宽度条件的误杀率。
- 三张中文图已用实际冒烟数据验证，标明不作评估，使用规定字体及 150 dpi。证据记录、中文报告、export-case 与 evidence check 已接入 make surrogate3；本阶段按要求不导出案例。
