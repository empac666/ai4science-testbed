# 第八轮结果报告：N87 混合采样确认与无支撑单侧外推

## 摘要

在同一数据集的新随机划分与新种子下，H1/H2 正式拒绝，**M-X7 与 M-NI10-X7 成立**。后者仅表示 M 对 A 达到预注册的 10% Winkler 非劣界内的经验非劣。本轮是同一 N87 数据集上的新随机化确认，不是新材料或新测量数据上的独立复现。

E2 的 XF 与 XT 两个方向均为：**Winkler 检验拒绝，但最终有效优越结论不成立**。A-F、M-F、A-T、M-T 均未满足工程有效性与名义覆盖诚实度要求。XFT 仅描述性报告。较低的 Winkler 分数不能替代覆盖条件。

结果表由只读脚本 `scripts/m9_report_tables.py` 生成。脚本读取首次封存结果、逐臂表和校准文件，核对已有复算摘要，不拟合模型、不重放采集、不重新枚举检验。设计规模另读取冻结的 `split_summary.json`。下文自动区块保留脚本原始输出；实验数字均来自这些区块。日期、提交与执行配置按用户提供的执行记录及预注册列出。

## 2. 设计

详见 `docs/prereg/M9_magnet_round8_prereg.md`。A 为主动采样，M 为 dB/dt 分档混合采样，R 为随机采样。各实验固定一次族划分；每实验 K=30 个配对组，每组共享 S0 的 100 点，新增 6 批、每批 20 点，最终每臂 220 点。跨实验同号组不作配对。

E1 移除 X7（原始频率不低于 200 kHz 且幅值不低于 0.10 T，跨全部温度），从不含 X7 点的族中留出 G7r 与 CAL7r。X7 是有频率和幅值两侧支撑的角落外推，不能推广到任意无支撑区域。

E2 只允许频率设定点低于 300 kHz 且温度不高于 70 °C 的支撑区进入训练、采集和校准。XF 留出高频侧，XT 留出 90 °C 层，XFT 同时留出两者。XT 允许同族低温样本进入支撑区，因此是温度外推，不是新族外推。

## 3. 主假设（固定顺序 H1→H6）

W 表示每臂最终评估集的平均 Winkler 分数，越低越好。全部配对差进入检验，不因覆盖不合格删组。精确单侧符号翻转检验沿预注册顺序进行，拒绝阈值为 p<0.05。

IQR 列为 Q75−Q25，分位数用 NumPy 默认线性插值。标准化效应量 δ=mean(d)/sd(d, ddof=1)。相对降幅用“参照方法均值减目标方法均值，再除以参照均值”：H1/H3–H6 参照 R；H2 参照 A，**不把非劣界移位算作降幅**。H2 的 δ 则按预注册的移位差定义。相对降幅与 δ 仅为描述性效应汇总。

## 4. 有效性条件

每方法至少 26/30 臂通过，才满足相应经验重复性标准。这不是总体覆盖率的置信下界。

E1：C1 要求 G7r 覆盖达到 80%；C2 要求 X7 覆盖达到 80%，且 X7 宽度不超过 G7r 的 3 倍；CV 计同时通过 C1/C2 的臂。

E2：C1 要求 G8 覆盖达到 80%；V80-F/T 还要求目标区域达到 80%，且宽度不超过 G8 的 3 倍。HONEST90-F/T 只计目标区覆盖达到 90% 的臂，不混入宽度或 G8 条件。下表覆盖数均向上取整；XFT 的两列、E1 与 G8 的 90% 列仅作参考，不新增判据。

## 7. 只报告项、解读与局限

**过覆盖。** E1 的 A/M 在 X7 上覆盖接近全覆盖，逐臂范围见上表。Winkler 几乎等于区间宽度，漏覆盖罚分很少。这说明全局 q 在 X7 上偏保守，不是条件覆盖保证。G7r 的覆盖与 X7 不同，不能由 X7 的表现断言校准在各区域都合适。“CAL7r 整族重尾残差撑大 q”只是未检验假说。

## 10. 建议下一步

1. 先预注册覆盖修正方案，再用新数据检验。把频率、温度方向分开设计，不以降低覆盖目标换取结论成立。

3. 为磁学机理假说设计额外测量或模型比较。当前负偏差只能定位问题，不能判定机制。
4. 用新材料或新测量数据做独立复现；在新轮次冻结前清理小 K 遗留分支，并增加相应边界核验。保留本轮封存文件和判定。
