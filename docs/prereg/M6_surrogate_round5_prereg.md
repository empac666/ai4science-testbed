# DC-link 代理模型第五轮预注册：K=6 组配对（主动 A / 混合 M / 随机 R），在全新留出集上做方法层面比较

**提交时间要求**：本文件与冻结配置 `lab/cases/dclink5/config_prerun.json` 一起，在生成任何第五轮输入设计或仿真数据**之前**提交并推送。第五轮新留出集与随机臂的 LHS 种子由**本文件所在提交的 SHA** 决定（第 3 节），因此在提交前无法预知。设计生成后另做一次冻结提交（设计哈希），然后才开始仿真。
**起因**：第四轮裁定（`docs/reports/M5_moderator_rulings.md`）留下的问题：
1. A 与 M 各只有一次实现，A 的结果在设计前已知，无法做方法层面的结论（R4-01、R4-02）；
2. 没有多重比较校正；
3. 逐点 Wilcoxon 存在伪重复（R4-05）；
4. 评估集都已看过（R4-04 中的补充集问题）。
本轮全部推断都以"配对"为单位（K=6），在全新仿真、从未看过的留出集上进行，并用固定顺序检验控制族错误率。**第一至四轮的判定都不追溯修改。**

## 1. 不变的部分
仿真（film，C_ratio=1，6 s，startup 1 s，dt 50 ns，be9a0f4，非理想传感器）；目标 y；M2 模型（配置与第三、四轮 `config_prerun.json` 的 model 节逐字相同）；σ 归一化 split conformal（在第三轮 calib 60 上校准，q 取第 55 个顺序统计量）；每臂训练集 = S0（第二轮非理想 E-in 150）+ 本臂 110 个新增点。A 的采集规则同第三轮（σ believer，5×22），M 的规则同第四轮（σ/√(1+a_c)，5×22），候选池用第三轮 `pool.json`（每臂只排除自己已选的点），R 为完整域上 110 点 LHS（dead_time 取 7 类）。

## 2. 配对设计与 K 的选择
- 第 k 组（k=1…6）包括 A_k、M_k、R_k 三个臂，三臂共用同一初始数据 S0，但每例使用独立的噪声种子 `nonideal_seed = 20290000 + index`。R_k 的 LHS 种子各不相同。
- 由于 S0 固定，所有 A_k（以及所有 M_k）的第 1 批选点相同，从第 2 批起才因噪声不同而分化。所以组间变异来自：传感器噪声的实现、随机臂的 LHS 抽样，以及自适应臂经由带噪 y 产生的路径依赖。结论是**以 S0 为条件**的方法层面结论（"从这个初始数据出发重新跑一次该方法"），不涵盖初始设计本身的变异。
- **K=6 的理由**：每个检验是 K 个配对差上的精确单侧符号翻转置换检验，最小可达 p = 1/2^K。K=5 时最小 p = 0.031，必须 5 组全部同向；K=6 时最小 p = 0.016，而且允许 1 组幅度较小的反向（p = 2/64 = 0.031 < 0.05）。K=8 时容错更多，但成本高。按第四轮实测（2 进程约 6.4 例/分钟），各方案的新仿真量与耗时：K=5 为 1790 例、约 4.7 h；**K=6 为 2120 例、约 5.5 h**；K=8 为 2780 例、约 7.2 h。效应量参考第四轮：A 与 5 个随机臂的角落 Winkler 差为 0.64–2.08，全部为正。所以 H1/H2 在 K=6 下功效充足；H4 的效应较小（第四轮只有一个差值 0.11），功效未知。综合取 K=6。

## 4. 每臂指标
在 C5 上：覆盖数、平均宽度、平均 Winkler（α=0.1）W̄(C5)。在 D5 上同样，W̄(D5)。在 T5 上：覆盖数与平均宽度。

## 5. 主假设（配对层面，固定顺序检验）
每个假设定义一个配对差 d_k（k=1…6），检验 H₀：d_k 的分布关于 0 对称，H₁：均值 > 0。p 值为精确符号翻转置换 p：p = #{s∈{±1}⁶ : mean(s·d) ≥ mean(d)} / 64（含恒等变换，平局计入）。
| 顺序 | 假设 | d_k |
|---|---|---|
| H1 | 主动优于随机（角落） | W̄_R,k(C5) − W̄_A,k(C5) |
| H2 | 混合优于随机（角落） | W̄_R,k(C5) − W̄_M,k(C5) |
| H3 | 混合在角落不劣于主动（非劣界 10%） | 1.10·W̄_A,k(C5) − W̄_M,k(C5) |
| H4 | 混合在 dt3 上优于主动 | W̄_A,k(D5) − W̄_M,k(D5) |

**多重比较**：固定顺序 H1 → H2 → H3 → H4，每步 α = 0.05；某一步未拒绝即停止，之后的假设记为"未检验"，名义 p 只报告。族错误率 ≤ 0.05。所有推断都以 6 个配对为单位，不在点层面做检验，以避免伪重复。

## 6. 覆盖与宽度判据（方法层面的有效性条件）
- 每个臂：C1 T5 ≥ 48/60；C2-corner C5 ≥ 32/40，且平均宽度 ≤ 3 × 该臂 T5 平均宽度；C2-dt3 D5 ≥ 32/40，宽度条件同上（门限同第三轮）。
- **CV-X**（X ∈ {A, M, R}）：6 个臂中至少 5 个通过全部三项。若各臂独立且可交换，单臂三项联合误杀率约 10–12%，则 CV 的误杀率约 12–16%。这是有效性条件，不属于发现性检验，不做多重校正。

## 7. 结论规则
- **结论 A**（主动采样在方法层面优于随机，以 S0 为条件）⇔ H1 被拒绝 且 CV-A 成立。
- **结论 M**（混合采集优于随机）⇔ H2 被拒绝 且 CV-M 成立。
- **结论 M≈A**（混合在角落不劣于主动）⇔ H3 被拒绝。
- **结论 M>A(dt3)** ⇔ H4 被拒绝。
- 只报告、不判定：每组的全部差值；各臂的 MAE、偏差、q；各臂在角落与 dt=3 上的采点数，以及 M 臂 dt=3 点数 ≤ 27 的组数；R 臂在 C5 上的覆盖分布；旧留出集上的结果；M0/M1。
