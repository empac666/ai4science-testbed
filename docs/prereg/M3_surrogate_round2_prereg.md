# DC-link 代理模型第二轮预注册（里程碑 3；在生成任何第二轮数据、拟合任何第二轮模型之前提交）

起因：第一轮主判据未通过（GP 标准保形区间在 OOD 上的覆盖率为 40%）。本轮按照 `docs/reports/M2_moderator_rulings.md` 的建议重新设计。**第一轮的判定不追溯修改。**

## 1. 数据
仿真与第一轮相同：film 电容，C_ratio=1，时长 6 s，startup 1 s，solver dt 50 ns，源码为快照 dclink-edge-ai@be9a0f4，目标 y 的定义也相同。

### 新的理想传感器数据（dclink2）
设计种子为 20261004，全部为新抽取的点：
- **E-in**：分布内 150 例。在 load ∈ [0.30, 1.00]、dead_time ∈ {0, 0.5, …, 2.5} µs、bw_iac ∈ [50, 400] kHz（对数均匀）、aperture ∈ [0, 30] µs 上做拉丁超立方抽样。抽样数量取 600，按顺序剔除落在角落区域（load ≤ 0.35 且 bw ≤ 75）的点，然后取前 150 个。
- **E-dt3**：OOD 子集，30 例。dead_time 固定为 3.0 µs，其余三个维度在全范围上做拉丁超立方抽样。
- **E-corner**：OOD 子集，30 例。load ∈ [0.30, 0.35]，bw ∈ [50, 75] kHz（对数），dead_time ∈ {0, …, 2.5}，aperture ∈ [0, 30]，用拉丁超立方抽样。

### 非理想传感器对照组（dclink2_nonideal）
- 使用与上面相同的 210 个参数点，设置 `SensorConfig(ideal=False)`，打开噪声和增益误差。
- 每例使用独立种子：seed_i = 20261004 + i，i 为该点在 210 例中的序号。

## 2. 划分
划分在训练前冻结，并写入哈希。
- **train**：第一轮全部分布内样本，共 200 例（即第一轮的 train、calib、test 三部分）。
- **calib / test**：E-in 按种子 20261005 随机打乱后对半分，各 75 例。
- **OOD 主评估集**：E-dt3（30 例）和 E-corner（30 例），全部是本轮新抽取的点。
- **补充评估**：第一轮的 40 个 OOD 样本已经看过结果，所以不进入主判据，也不进入训练，只作为补充报告。

## 3. 方法
所有方法的配置在运行前固定，结果只认第一次运行。
- **M0**：第一轮的 GP 配置，配标准 split conformal。作为参照。
- **M1**：同样的 GP，配 σ 归一化 conformal。打分为 |r|/σ_GP，区间为 ŷ ± q·σ。
- **M2（主方法）**：
  - 均值部分用线性最小二乘，在 train 上拟合 reviewer_b 提出的主效应解析模型：ŷ_lin = β0 + β1·t_dead·f_c + β2·load + β3·f_grid/bw_iac + β4·4π·f_grid·t_ap。
  - 线性模型的残差用 GP 拟合，GP 配置与第一轮相同。
  - 区间用 σ 归一化 conformal。
- **M3**：只用 reviewer_b 的解析模型，配标准 conformal。
- **M4**：第一轮的 MLP 配置，配标准 conformal。作为参照。
- **M5**：researcher_a 第一轮的解析模型（t_dead·f_c/load 等特征），配标准 conformal。作为参照。

所有 conformal 的分位数都按 ceil((n+1)·0.9)/n 取，名义覆盖率为 90%，calib 集 n=75，对应第 69 个顺序统计量。

## 4. 判据
主方法为 M2，在理想数据上评估，覆盖率和区间宽度一起考核。

| 编号 | 判据 | 阈值依据 |
|---|---|---|
| C1 | in-dist test（75 例）的覆盖数 ≥ 62/75（82.7%） | 在严格可交换的前提下，这个阈值误杀的概率为 4.5%（beta-binomial(75; 69, 7)） |
| C2-dt3 | E-dt3 覆盖数 ≥ 24/30（80.0%），**并且**平均区间宽度 ≤ 3.0 × in-dist test 平均宽度 | 可交换时误杀概率 3.8%；宽度上限是为了排除"靠无限放宽区间来达标" |
| C2-corner | E-corner 满足与 C2-dt3 相同的两个条件 | 同上 |

- **总判定**：C1、C2-dt3、C2-corner 全部满足才算通过，否则不通过。
- **只报告、不判定的项目**：
  - 各方法在各集合上的 MAE、最大误差、偏差、覆盖率、宽度；
  - 非理想对照组：|y_nonideal − y_ideal| 的分布，以及在理想数据上校准的 M2 在非理想数据上的覆盖率；
  - 第一轮 OOD 的补充结果；
  - M3 与 M5 两种解析模型的比较。
