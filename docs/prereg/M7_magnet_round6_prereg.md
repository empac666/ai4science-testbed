## 1. 框架：池式主动学习
- "仿真器" = 对实测池的查表：查询池中一个 `sample_id` 只揭示其实测损耗 y，别无其他。
- 目标 y = log10(实测体积损耗 [W/m³])。
- 输入特征（只由 B 波形、f、T 计算，不用任何损耗信息）：log10 f、log10 Bpk、T、上升占空比 duty、平台比例 plateau、波形形状因子 shape = log10(mean(|dB/dt|^1.5)/(4fBpk)^1.5)。精确定义见冻结配置。
- 模型（M2-magnet，沿用第三至五轮 M2 结构）：在 [1, log10 f, log10 Bpk, T, T², shape] 上做 OLS 线性均值（Steinmetz 型的 log 线性项 + 温度二次项），残差用 ARD-RBF + White 的 GP 拟合（6 维标准化输入），σ 归一化 split conformal（α=0.1）。每批重新优化超参数。
- 不使用 W2 的 iGSE 预测作为特征（其参数拟合用到了部分正弦样本，可能与留出集重叠）；iGSE 只作只报告的基线。

## 2. 角落（困难区）与分布内留出集的定义与理由
**角落 = f ≥ 200 kHz 且 Bpk ≥ 0.10 T**（Bpk = 峰峰值/2）。共 632 个样本（占 1.6%），四个温度各 158 个，其中三角波 580、梯形波 52、正弦 0。

物理理由：
1. 这是损耗密度最高的区域（P ∝ f^α B^β，α≈1.4–2.0、β≈2.6），对应高频高磁密的设计极限，热设计最关键；
2. 高 dB/dt 下弛豫与涡流等附加损耗机制加强，Steinmetz 参数随频率漂移，iGSE 类经验模型在此外推最不可靠；
3. 测试台功率受限，数据在此最稀疏（1.6%），而工程师的初始表征通常覆盖典型工况。因此角落是"数据稀、物理难、工程上重要"的真实困难区，作为主动采样是否值得的检验区。

不另设"直流偏置"或"非正弦"角落：本数据集（MagNet 预训练集 N87）不含直流偏置；非正弦波形（三角/梯形）占 96.5%，本身就是主体。

## 3. 划分与种子（全部在本文件提交之后生成）
记 H = int(本预注册提交 SHA 的前 8 个十六进制字符, 16)。
| 集合 | 数量 | 生成方式 |
|---|---|---|
| C6 角落留出集 | 200 | `rng=default_rng(H)`；`rng.permutation(按 id 排序的角落 id)[:200]` |
| T6 分布内留出集 | 300 | 同一 rng 继续：`perm=rng.permutation(按 id 排序的非角落 id)`；`perm[:300]` |
| CAL6 校准集 | 100 | `perm[300:400]`（非角落，所有臂共用） |
| 候选池 | 40016 | 全部 − C6 − T6 − CAL6（含 432 个角落样本） |
| S0_k 初始集 | 100 | `default_rng(H+k).choice(池∩非角落, 100)`，k=1…8 |
| R_k 随机臂 | 120 | `default_rng(H+100+k).choice(池−S0_k, 120)`，抽样顺序即采集顺序 |
| A_k、M_k | 各 120 | 6 批 × 20，从 池−S0_k−本臂已选 中选取 |

C6/T6/CAL6 在任何臂的采集与训练中都不可见（实现须在读取 y 之前按 id 过滤，并有断言）。

## 4. 配对设计与 K 的选择
- 第 k 组（k=1…8）包括 A_k、M_k、R_k，三臂共用同一初始集 S0_k。**与第五轮不同，S0_k 每组不同**，因此组间变异包括初始设计本身的变异，结论不再"以单一 S0 为条件"。测量数据查表无噪声，组内路径差异全部来自方法本身。
- **K=8**：每个检验是 8 个配对差上的精确单侧符号翻转置换检验，最小可达 p=1/256≈0.0039；允许 1–2 组幅度较小的反向仍可能 p<0.05。查表代价为零，计算代价低（估计全部 24 臂约 1–2 h），故取 K=8 而非 6。真实数据上的效应量未知，K=8 提高功效。
- 每臂预算：S0 100 点 + 新增 120 点（6×20）。

## 5. 采集规则
- **A**：GP 后验标准差（含 WhiteKernel）的 kriging believer：同一批内固定超参数与 y 归一化，逐点增广 Cholesky，取 argmax σ（与第三轮相同）。
- **M**：同一 believer，得分 σ/√(1+a_c)，a_c = 本臂（不含 S0）已选点中与候选同一单元的点数；单元 = 波形类别（3）× 温度（4）= 12 个（与第四轮"按类别分散"的思想对应）。
- **R**：按预抽顺序取点，不用模型。

## 6. 每臂指标（最终模型 = S0_k + 本臂 120 点，CAL6 校准）
在 C6、T6 上分别计算：覆盖数、平均宽度（log10 单位）、平均 Winkler 分数 W̄（α=0.1，log10 单位）、点预测中位相对误差 RE = median|10^μ − P|/P。

## 7. 主假设（配对层面，固定顺序检验）
H₀：d_k 的分布关于 0 对称；H₁：均值 > 0。p = #{s∈{±1}⁸ : mean(s·d) ≥ mean(d)} / 256（含恒等变换，平局计入）。
| 顺序 | 假设 | d_k |
|---|---|---|
| H1 | 主动优于随机（角落 Winkler） | W̄_R,k(C6) − W̄_A,k(C6) |
| H2 | 混合优于随机（角落 Winkler） | W̄_R,k(C6) − W̄_M,k(C6) |
| H3 | 混合在角落不劣于主动（非劣界 10%） | 1.10·W̄_A,k(C6) − W̄_M,k(C6) |
| H4 | 混合在角落的点预测相对误差优于随机 | RE_R,k(C6) − RE_M,k(C6) |
| H5 | 混合在分布内不劣于随机（非劣界 10%） | 1.10·W̄_R,k(T6) − W̄_M,k(T6) |
| H6 | 主动在分布内不劣于随机（非劣界 10%） | 1.10·W̄_R,k(T6) − W̄_A,k(T6) |

**多重比较**：固定顺序 H1→H2→H3→H4→H5→H6，每步 α=0.05；某一步未拒绝即停止，之后记为"未检验"，名义 p 只报告。族错误率 ≤ 0.05。所有推断以 8 个配对为单位，不在点层面做检验（避免伪重复）。

## 8. 有效性条件（CV）
- 每臂：C1 T6 覆盖 ≥ 240/300；C2 C6 覆盖 ≥ 160/200 且 C6 平均宽度 ≤ 3 × 该臂 T6 平均宽度。
- **CV-X**（X∈{A,M,R}）：8 个臂中至少 7 个同时通过 C1 与 C2。有效性条件不做多重校正。
- 流程有效性：24 臂全部完成；任何臂训练集与 C6/T6/CAL6 交集为空；所有选点可由冻结批次文件复现。若某臂因故障中断，从冻结批次断点确定性续跑，不得因结果剔除任何臂。

## 9. 结论规则
- **结论 A**（真实数据上主动优于随机，角落）⇔ H1 拒绝 且 CV-A。
- **结论 M**（混合优于随机，角落）⇔ H2 拒绝 且 CV-M。
- **结论 M≈A**（混合角落不劣于主动）⇔ H3 拒绝。
- **结论 M-RE**（混合角落点预测更准）⇔ H4 拒绝。
- **结论 M-ID**（混合不损害分布内）⇔ H5 拒绝 且 CV-M；**结论 A-ID** ⇔ H6 拒绝 且 CV-A。
- 只报告、不判定：全部配对差；各臂 q、MAE、偏差、覆盖、宽度；学习曲线（每批后 C6/T6 指标，R 用前 20b 点）；各臂角落采点数与单元分布；iGSE 基线在 C6/T6 上的中位相对误差；未检验假设的名义 p。
