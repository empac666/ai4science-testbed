# 第七轮预注册：MagNet N87 上的**真外推**检验 —— 整区域与整激励族留出，主动 A / 混合 M（dB/dt 分档）/ 随机 R，K=20 组配对

**提交时间要求**：本文件与冻结配置 `lab/cases/magnet7/config_prerun.json` 一起提交并推送，时间早于任何第七轮划分、模型训练或指标计算。留出族的选取与各配对的初始集、随机臂种子都由**本文件所在提交的 SHA** 决定（第 3 节）。

**起因**：第六轮（`docs/reports/M7_magnet_round6.md`）中，结论 A 成立，但效应小而脆弱。原因已查明：97.5% 的角落留出点在池中有“同一激励、不同温度”的孪生点，所以“角落”并不是外推（裁定 R6-C04）。本轮按第六轮建议 #1，把孪生点整体移出候选池，检验真正的外推。第一至六轮判定不追溯修改。

**预注册前已知信息（如实披露）**：第六轮全部结果，包括第六轮角落 = 本轮 X7。写本文件前，主持人只查看了**输入侧**统计：频率设定点聚类（共 20 个，50–446 kHz）、激励族数（291 个，中位 88 个样本/族）、族的温度完整性（278 族含全部 4 个温度）。还做了输入空间孪生检查：X7 整体移出后，其点到池中最近邻（5 维形状特征，不含温度）的距离均 ≥0.01，中位 0.27；第六轮为 97.5% 的点 <0.01。本轮划分上未训练任何模型，也未查看任何第七轮的损耗值。

## 1. 不变的部分
目标 y = log10(实测体积损耗)。特征、M2-magnet 模型（OLS 线性均值 + 6 维 ARD-RBF+White 残差 GP + σ 归一化 split conformal）、believer 采集、指标定义，均与第六轮冻结配置逐字相同；只有校准集不同（第 3 节）。复用第六轮特征文件 `data/magnet6/features.csv`（SHA256 `781a7048…`，由第六轮 `magnet6_design.py --verify` 可复现）。

## 2. 困难集的定义与理由
**X7 外推区（连续 f–Bpk 区域，所有温度一起移出）**：f ≥ 200 kHz 且 Bpk ≥ 0.10 T，共 632 个样本，覆盖 4 个温度与 224–397 kHz 的 6 个频率设定点。
- 该区域**整体**从候选池与校准集中移除，任何臂都无法采到其中的点，也没有跨温度孪生点。预测只能依靠区域外的数据外推。
- 物理意义同第六轮：高频高磁密，损耗密度与 dB/dt 最高，iGSE 最不可靠（第六轮 iGSE 中位误差 17.9%）。工程上相当于“已知 200 kHz 以下或 0.1 T 以下的数据，外推到更高功率密度的设计点”。
- 评估用 X7 全部 632 个样本。

**G7 新激励族（整族留出）**：激励族 = 频率设定点 × 波形形状（波形类别、round(10·duty)、round(20·plateau)），即一种波形在一个频率下、在全部幅值与 4 个温度上的扫描。从不含 X7 样本的族中，按种子随机取 **40 个族**，族内全部样本作为 G7。
- 同一激励的 4 个温度，以及同一族的其它幅值，都不在池中。预测只能借助相邻频率、相邻形状的族，属于“新激励”泛化。
- 选第一个变体（整区域）作为 H1，是因为它是最纯粹的外推；整族留出作为 H2，对应用户提出的“整激励留出”。

**CAL7 校准集**：再取 20 个族的全部样本（与 G7 同样按族划分，使校准与“新激励”可交换）。不含 X7，因此 X7 的覆盖完全依赖 σ 的外推行为，这正是本轮要检验的内容之一。

## 3. 划分与种子
记 H = int(本预注册提交 SHA 的前 8 个十六进制字符, 16)。
| 集合 | 生成方式 |
|---|---|
| X7 | 规则确定（632 个样本），与种子无关 |
| G7 / CAL7 | `rng=default_rng(H)`；`perm=rng.permutation(按键名排序的非 X7 族)`；G7 = perm[:40] 的全部样本，CAL7 = perm[40:60] 的全部样本 |
| 池 | 全部 − X7 − G7 − CAL7 |
| S0_k | `default_rng(H+k).choice(sorted(池), 100)`，k=1…20 |
| R_k | `default_rng(H+100+k).choice(sorted(池−S0_k), 120)`，抽样顺序即采集顺序 |
| A_k / M_k | 6 批 × 20，从 池−S0_k−本臂已选 中选取 |

G7 与 CAL7 的样本数由族决定（预计各约 3000–6000 与 1500–3000），在设计冻结时记录。

## 4. 方法
- **A**：σ believer（同第六轮）。
- **M（重新设计）**：σ/√(1+a_c)，单元 = log10(4·f·Bpk)（与平均 |dB/dt| 成正比，是损耗密度与外推方向的主导量）在**池**范围内的 8 个等宽分档。等宽分档使高 dB/dt 的稀疏档也有同等配额，因此 M 的分散方向与困难维度一致。按用户要求，只有单元跟踪困难维度时才保留 M；这里满足该条件。
- **R**：预抽顺序。

## 5. K 的选择与功效
- **K=20**：精确符号翻转共 2^20 种，最小 p≈9.5e-7。
- 功效模拟：每种 K 抽 400 次，单侧 α=0.05，按配对差标准化效应 δ = mean/sd。
  - 以第六轮 H1 配对差为参照（均值 0.0089、sd 0.0147，δ≈0.60）：
    - 正态近似下，K=8/12/16/20 的功效依次为 0.45/0.61/0.75/**0.81**；
    - 从第六轮 8 个差值做 bootstrap，功效依次为 0.66/0.92/0.99/**1.00**。
  - δ=0.4 时，K=20 的功效约 0.57。
- 计算代价：第六轮 24 臂共 2.1 min，本轮 60 臂预计 < 15 min。取 K=20，使功效在小效应下也达到约 0.8。
- 真外推时效应可能更大（随机臂没有任何区域内的点），也可能更小（主动臂同样采不到区域内的点）。本轮不预设方向强度。

## 6. 每臂指标（最终模型 = S0_k + 本臂 120 点，CAL7 校准）
在 X7、G7 上分别计算：覆盖数、平均宽度、平均 Winkler W̄（α=0.1，log10 单位）、中位相对误差 RE = median|10^μ−P|/P。

## 7. 主假设（配对层面，固定顺序）
H₀：d_k 的分布关于 0 对称；H₁：均值 > 0。p = #{s∈{±1}^20 : mean(s·d) ≥ mean(d) − 1e-12} / 2^20。
| 顺序 | 假设 | d_k |
|---|---|---|
| H1 | 主动优于随机：外推区 Winkler | W̄_R(X7) − W̄_A(X7) |
| H2 | 主动优于随机：新激励族 Winkler | W̄_R(G7) − W̄_A(G7) |
| H3 | 主动优于随机：外推区点预测相对误差 | RE_R(X7) − RE_A(X7) |
| H4 | 混合（dB/dt 分档）优于随机：外推区 Winkler | W̄_R(X7) − W̄_M(X7) |
| H5 | 混合在外推区不劣于主动（非劣界 10%） | 1.10·W̄_A(X7) − W̄_M(X7) |

固定顺序 H1→H5，每步 α=0.05；某一步未拒绝即停止，之后记为“未检验”，名义 p 只报告。族错误率 ≤ 0.05。推断单位是 20 个配对，不在点或族层面做检验。

## 8. 有效性条件（CV）
- 每臂需满足：
  - C1：G7 覆盖 ≥ ceil(0.8·|G7|)；
  - C2：X7 覆盖 ≥ 506/632，且 X7 平均宽度 ≤ 3 × G7 平均宽度。
- **CV-X**：20 个臂中至少 17 个同时通过 C1 与 C2。
- 外推区覆盖可能对所有方法都失败。此时即使 H1 拒绝，结论 A-X 也不成立。这是有意的要求：外推上的区间必须诚实。
- 流程有效性：60 臂全部完成；所有训练集与 X7、G7、CAL7 的交集为空；选点可由冻结批次复现；不得因结果剔除任何臂。

## 9. 结论规则
- **A-X**（主动在真外推区优于随机）⇔ H1 拒绝 ∧ CV-A。
- **A-G**（主动在新激励族上优于随机）⇔ H2 拒绝 ∧ CV-A。
- **A-RE**（主动在外推区点预测更准）⇔ H3 拒绝。
- **M-X**（dB/dt 混合在外推区优于随机）⇔ H4 拒绝 ∧ CV-M。
- **M≈A**（混合在外推区不劣于主动）⇔ H5 拒绝。
- 只报告：全部配对差及其均值、中位数、IQR、正值组数；各臂 q、MAE、偏差、覆盖、宽度；学习曲线；前沿采点数（X7 之外、f ≥ 150 kHz 且 Bpk ≥ 0.07 T）；dB/dt 分档分布；iGSE 在 X7/G7 上的中位相对误差；未检验假设的名义 p。
