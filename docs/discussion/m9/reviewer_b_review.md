## 2. 代码评审（逐文件审查）

### 2.1 `scripts/magnet8_common.py`
- **标签隔离与权限控制（良好）**：`PoolReader` 类通过 `authorized` 严格限定每臂当前步可见集合；`read_targets` 函数强制白名单校验（`ids <= allowed`）与黑名单碰撞拦截（`not ids & forbidden`），并在底层 `pd.read_csv` 时采用 `skiprows` 跳过未请求行，防止内存常驻与隐式全表读取。
- **模块与配置深度隔离（良好）**：`adapter(e)` 采用 `importlib.util.module_from_spec` 动态加载，对 `CONFIG` 进行 `copy.deepcopy` 并覆盖 `gp_seed(e)`，彻底消除了历史轮次因共享全局模块字典导致的跨臂随机种子污染问题。
- **不可变原子写入（良好）**：`atomic`（临时文件加 PID 写入后 `os.replace`）与 `freeze`（`xb` 独占创建，已存在则强制比对字节）实现双重防护，杜绝了静默覆盖可能。
- **轻微问题**：`read_targets` 内部每次调用均读取一次 `header = pd.read_csv(SOURCE, usecols=['sample_id'])`，虽保证无状态，但在大样本批次下存在少量无谓 I/O 开销（轻微性能开销，不影响正确性）。

### 2.2 `scripts/magnet8_arm.py`
- **采样与拟合解耦（良好）**：每步循环先拟合 $b$ 步模型，封存无标签 `predictions_{b}.csv`，其后再通过 `choose` 计算采集分并封存 `batch_{b+1}.json`，最后调用 `reader.authorize(chosen)` 解锁下一批真值。时间线严格单向流动。
- **有效性与采样计数解耦（良好）**：新增 `sampling_stats` 函数，提取频点、温度、边界点等详细统计信息，输出至独立的 `sampling_counts` 字段，彻底修复了 R7-C01 中采样计数覆盖有效性通过计数的重大缺陷。
- **中等问题**：`sampling_stats` 中将边界点 `boundary_282` 与 `boundary_70` 进行了硬编码（对应 E2 支撑区边界），但在 E1 运行中该字段依然被计算并写入。由于 E1 支撑与池规则不同，E1 输出中的 `boundary_282` 缺乏物理意义，建议在元数据中注明仅供参考或按实验分支输出。

### 2.3 `scripts/magnet8_audit.py`
- **零标签全面审计与重放（优秀）**：`audit_results` 在接触真值前对所有 180 臂的配置文件、模型状态、预测文件、候选池指纹实施严格校验。
- **全量 Acquisition 重放机制（优秀）**：通过 `--replay-arms all`，利用储存的 scaler 参数与核超参数 $\theta$，独立重构高斯过程残差代理并在 `rtol=1e-8` 精度下复算 Kriging believer / Mixed believer 的采集序列与打分，证实 180 臂采集无一作伪。

### 2.4 `scripts/magnet8_calibrate.py`
- **门控锁机制（良好）**：通过 `out/'CALIBRATING'` 独占文件锁，且运行前必须通过 `require_complete(source)` 与 `audit_results`，确保 180 臂全部安全封存后才打开 CAL 标签。
- **校准秩实现（良好）**：严格遵循分位数定义 `rank = math.ceil((len(scores) + 1) * 0.9)`，并使用 `np.partition(scores, rank - 1)[rank - 1]` 提取顺序统计量 $q$。由于 Python 为 0 索引，`rank - 1` 正好对应第 $rank$ 个元素，断言检查了 `rank <= len(scores)` 及 $q \ge 0$。

### 2.5 `scripts/magnet8_evaluate.py`
- **主终点 Winkler 与覆盖率实现（良好）**：严格实现公式 $W = (U - L) + 20(L - y)\mathbf{1}_{y < L} + 20(y - U)\mathbf{1}_{y > U}$，区间取闭区间 $[L, U] = [\mu - q\sigma, \mu + q\sigma]$。
- **MITM 符号翻转与尺度容差（良好/轻微隐患）**：
  - 折半查找 Meet-In-The-Middle 算法逻辑完备，分子采用 64 位整数累加，分母为严格的 $2^{30}$。
  - 阈值设定为 `float(d.sum()) - len(d) * 1e-12`，在总和尺度上进行无偏比较。
  - **轻微/中等问题（遗留分支）**：代码第 30–48 行保留了 `if len(d) <= 14:` 的兼容分支，针对极小组数通过浮点 ULP 边界展开重算。在预注册 $K=30$ 的主路径中，该分支永远不会被触发（死代码），但保留未经充分注释的复杂回退逻辑容易在跨平台代码审计中引发歧义。
- **固定顺序门控（良好）**：`fixed_sequence` 严格执行串行阻断，前一步若 `p >= 0.05` 则后序全部标记为 `not_tested`。
- **iGSE 处理隔离（良好）**：iGSE 基线预测指标仅在主科学评估产物 `primary_evaluation.json` 封存后才被读入，并在 `igse_note` 中明示了其按温度拟合可能包含 90 °C 正弦数据的先验偏差，符合预注册要求。

### 3.3 深度物理与统计现象剖析

1. **E1 X7 覆盖率 $\approx 100\%$ 的物理与统计含义**：
   - A、M、R 在 X7 上的经验覆盖率分别高达 99.95%、99.91% 和 98.38%（平均仅漏检 0.3 至 10 点，满分 632 点）。
   - **机理解释**：X7（$\ge 200\text{ kHz}, \ge 0.1\text{ T}$）虽属边缘角落，但在频率和磁通密度两侧均具有连续过渡支撑，且全温度（25–90 °C）均有数据。在 CAL7r（随机抽取的整族样本）上校准的置信分位数 $q$（均值约 1.57–1.60）主要反映了全域非线性拟合残差的分位数；当模型在支撑充足的 X7 区平滑插值且方差预测适度保守时，该 $q$ 值将预测区间撑大到了超出实际所需宽度的水平，导致了明显的**过覆盖（Over-coverage）**。这证明在数据分布不均匀且存在局部平滑先验时，全局单标量 Conformal 校准无法保证局部的严格紧致性。
2. **A/M 与 R 的宽度和偏差对比**：
   - **区间宽度**：在 E1 X7 上，M 的平均宽度（0.0547）略窄于 A（0.0571），两者均显著窄于 R（0.0661，窄约 17%）；在 E2 XF 上，A/M 宽度约为 0.071，而 R 高达 0.092。这印证了自适应主动学习能够有效消除模型在无知区域的不确定性。
   - **偏差表现**：在 E1 上，所有方法偏差极小（$|\text{bias}| < 0.009$）；而在 E2 上，A/M/R 均出现负偏，且 R 的负偏（XF: -0.0384, XT: -0.0355）显著劣于 A/M（XF: -0.0087 / -0.0078, XT: -0.0268 / -0.0280）。
3. **E2 外推的系统性负偏差与物理失效**：
   - 在 XF（高频）上，平均偏差约为 $-0.008$ 到 $-0.038$；在 XT（高温 90 °C）上，负偏加剧至 $-0.027$ 到 $-0.035$；在 XFT（高频且高温）上，**系统性负偏差呈现爆发性恶化**（A: -0.0637, M: -0.0664, R: -0.1305，对应真值在物理损耗原值尺度下被低估 15% 至 35%）。
   - **失效成因**：由于移除了高频与高温的所有支撑，GP 模型依靠低频/低温数据拟合的 Steinmetz 多项式均值函数在外推区无法捕捉到高频涡流损耗的非线性急剧爬升以及高温下磁芯饱和特性的恶化，先验均值曲线过于“扁平”，导致系统性低估。外推时均值预测下移，即使预测标准差 $\sigma$ 增大，置信上限 $U = \mu + q\sigma$ 依然无法包络急剧上升的实际损耗点，造成真实覆盖率断崖式下挫。
4. **逐臂离散度（Per-arm Dispersion）的警示**：
   - 在 E2 外推区，覆盖率呈现出剧烈的组间波动：
     - E2/A/XF：30 个臂的覆盖率从最低 48.0% 到最高 93.3%，跨度达 45 个百分点；
     - E2/A/XT：覆盖率范围为 [39.6%, 92.6%]；
     - E2/A/XFT：覆盖率在个别臂跌落至仅 4.2%（最低仅覆盖 75 / 1788 点）。
   - 这表明：**单侧无支撑外推的主动学习结果对初始抽样点 $S0$ 的几何分布极度敏感**。如果 $S0$ 碰巧未能抽中支撑区边缘（如 282 kHz 处），后续采集的主动探索将深陷局部次优，导致外推校准完全崩溃。单臂或少数臂的偶然达标绝不能代表算法的泛化稳健性。

## 6. 报告撰写时必须遵守的措辞约束

为维护 AI4Science 基准研究的科学诚信，后续主报告撰写必须无条件遵守以下措辞红线：

1. **E2 外推的定性红线**：
   - 严禁出现“外推成功（Extrapolation Succeeded）”、“无支撑外推有效（Valid Unsupported Extrapolation）”、“实现了可靠的高频/高温推广”等用语。
   - 规范用语：必须统一表述为“在无支撑单侧外推下，主动学习在 Winkler 惩罚损失上显著优于随机采样，但所有方法的区间覆盖诚实度均未能达到预注册的经验标准（HONEST90 失败），表现出显著的模型误设与系统性负偏差”。
2. **检验拒绝与结论成立的二元分离**：
   - 严禁将假设检验拒绝（$p < 0.05$）等同于最终科学结论成立。在提及 E2 时，必须明确写出：“虽然配对检验 H3–H6 在统计学上拒绝原假设，但由于工程有效性与覆盖诚实度门槛未达到 26/30 臂的预注册要求，最终结论 `A-F`、`M-F`、`A-T`、`M-T` 均为 False（不成立）”。
3. **H2 非劣关系的准确表述**：
   - 严禁将 H2 表述为“M 与 A 效果相同”、“两算法等价”或“M 取代 A”。
   - 规范用语：必须表述为“在 E1 X7 区域，混合分档采样 M 相对纯主动采样 A 达到 10% 劣化界限内的经验非劣（`M-NI10-X7` 成立）”。
4. **E1 X7 适用边界的界定**：
   - 严禁宣称“算法已解决角落数据分布的预测问题”。
   - 规范用语：必须明确指出 X7 是“在频率和磁通密度两侧具有连续支撑、且跨全部温度维度的有侧翼支撑角落验证”，不能推广至任意无支撑角落。
5. **iGSE 基线的从属地位**：
   - 不得将 iGSE 作为衡量外推优劣的公平竞争对手。提及 iGSE 时必须注明“仅作为参考性工程标尺，其温度分档拟合可能已利用了 90 °C 测量数据，因而不属于严格的单侧无支撑外推”。
6. **透明披露基础设施变更**：
   - 必须在报告的实验设置或局限性部分明确陈述看门狗内存阈值下调的操作记录，证明单线程执行的隔离有效性。
