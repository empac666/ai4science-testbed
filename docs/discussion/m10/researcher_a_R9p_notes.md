## 2. 设计取舍

**将覆盖作为主问题。** H1/H2直接比较逐臂90%覆盖欠缺g=max(0,0.90−c)，没有用Winkler替代诚实度。欠缺改善不等于达到90%；保留R8 V80/HONEST90及26/30门槛，增加平均覆盖≥90%。H3/H4限定Winkler的10%非劣，另加平均宽度≤1.50倍、每组≤2.00倍新基线。允许输出超限区间但结论失败，不通过裁剪“制造”成功。1.50/2.00是预先提出的工程取舍，不是根据未开放标签优化的常数。

**固定A，三种区间同轨迹。** B完整重跑R8-E2-A的全局q算法，E为去除偏差平移的消融，D为唯一主候选。既有背景足以把下一问题聚焦在校准，不需再次把M/R采集纳入正式链条。E及S0干预只报告，不因主候选失败而替补。新种子下的基线不是第八轮封存q；共同CAL让新方法与基线的差来自区间规则。

**用真正未参与影子拟合的伪边缘。** F影子核心≤199 kHz、边缘224/251/282；T核心≤50 °C、边缘70 °C。边缘训练点仅用于δ，边缘CAL点仅用于q，两类标签职责分开；最终主模型仍用全部220个查询点。这样避免额外购入边缘标签，也避免在CAL上估中心再计算其自身残差分位数。δ取有符号残差中位数，以减少少数极端点对平移的影响；不能把这解释为消除了适应性选择偏差。

**选择保留G/CAL规则并接受不可行风险。** 原规则在CAL的F边缘可能太稀。可通过分层抽CAL规避，但那会同时改变基线的校准分布，本稿不这样做。冻结最小20点/2族及不重抽规则。CAL少于2个F边缘族的组合概率约4.98%；点数、训练核心及S0配额条件还可能造成额外失败，不能把95.02%写成整体执行成功率。

**不新增局部距离权重。** 保留σ归一化，避免新带宽/核/截断参数引入可选择空间。方向性的q从影子模型转移到最终模型，仍是需要检验的经验迁移方法，不是已证明的局部条件覆盖。XFT中心加和与q取最大只是一条固定报告规则。

**S0为真实输入政策干预。** U是原均匀取100点；S用相同随机排列在六个f/T层取固定配额，频率边缘50点。两者都只查询220点，之后用相同A规则。D覆盖方差至少减半且欠覆盖不恶化是预定描述性支持条件；不做额外p检验。共同块/方法/交互平方和只描述结构，不能把共享组分量直接当作S0的因果方差比例。全部优化器种子固定，因此解释是S0连同其后续采集影响，不是只替换S0而保持最终训练集不变。

**统计计算清理。** C03不改R8封存实现；新R9统一整数化binary64精确值的MITM，去掉小K浮点容差回补。明确测试阈值附近、零重数和固定顺序，既保持2^30全符号精确计数，也消除不同求和结合顺序造成的小K补丁。只写未来要求，未实现或运行测试。
