## 二、分歧清单

### R7-C01：§D "CV 计数" 标签下的数据并非 CV 通过计数

**问题**：§D 写道"CV 计数（≥17/20）：`{'100': 173, '112': 123, …, '89': 87}`"。但该字典的 20 个键（50, 56, 63, …, 446）与预注册 §3 定义的 20 个频率设定点（fset）逐一对应，且数值合计恰好 2400 = 20 臂 × 120 点/臂，说明这是**某一方法的频率设定点采样分布**，而非各方法的 CV 通过臂数。代码 `aggregate()` 输出的 `CV_counts` 应为 `{'A': 20, 'M': 20, 'R': 20}` 形式，与后文 `CV：{'A': True, 'M': True, 'R': True}` 配套。报告此处混入了错误字段。

**补充核查**：该字典也不可能是 Active 的 fset 分布（解读叙述明确给出 A 的 446 kHz = 501、50 kHz = 383、56 kHz = 401，与此处 446→97、50→74、56→83 不符）；最可能是 R 臂的 fset 采样汇总（R 被描述为"大致均匀"，2400/20 = 120/setpoint，而实际值 61–173 的波动可解释为随机抽样变异）。

**严重度**：中。<br>
**是否影响预注册判定**：否——实际 CV 判定逻辑与代码一致，底层结论不变，但报告可读性受损，审计者无法从 §D 直接确认各方法的 CV 通过臂数（20/20 还是 18/20 等）。<br>
**建议**：在报告中补充真正的 `CV_counts`（如 `{'A': 20, 'M': 20, 'R': 20}`），并将当前误放数据移至采样分布段落，注明方法名。

### R7-C02：解读第 2 点称"效应仍小"，对 H2 不够准确

**问题**：解读第 2 点笼统称"效应仍小：X7 W̄ 降约 6%，G7 降约 9.5%"。数值本身无误（我复核：(0.0763−0.0717)/0.0763 = 6.0%，(0.0865−0.0783)/0.0865 = 9.5%）。但 H1 和 H2 的效应量差距悬殊：

| | mean(d) | 正值比 | p | 近似 δ=mean/sd |
|---|---|---|---|---|
| H1 (X7) | 0.00463 | 13/20 | 0.0209 | ≈0.48 |
| H2 (G7) | 0.00824 | 18/20 | 3.6e-5 | ≈1.2 |

H2 的 δ≈1.2 远超预注册功效模拟的参照 δ=0.60，18/20 为正，是强稳健的结论。笼统归为"效应仍小"会模糊两者的区别：H1 效应中等偏弱（δ<0.5），H2 效应大且极度稳健。

**严重度**：低。<br>
**是否影响预注册判定**：否。<br>
**建议**：分开描述。H1 可称"效应中等、统计上刚过门槛"；H2 应称"效应稳健、方向一致性极高（18/20 正）"。

### R7-C03：解读第 4 点"不是有针对性地靠近 X7"表述不够精确

**问题**：解读称"主动采样集中在频率两端（50/56/446 kHz）——域边界采样，不是有针对性地靠近 X7"。X7 的定义是 f ≥ 200 kHz ∧ Bpk ≥ 0.10 T。池中 446 kHz 的点（Bpk < 0.10 T）虽不在 X7 内，但在频率维度与 X7 共享最高频带，是 X7 在 Bpk 方向的直接邻域。主动在 446 kHz 大量采样（501/2400 = 20.9%）实质上**也**在为 X7 外推提供频率方向的约束。同样，f ≥ 150 kHz 的前沿采点（A 均值 11.65 vs R 10.15）也是 X7 近邻。

说"不是有针对性地靠近 X7"低估了高频采点对 X7 预测的贡献。更准确的表述是："主动采样集中在频率域的两端（其中 446 kHz 端恰好与 X7 的频率范围相邻），反映的是 GP 后验不确定性在域边界最大的机制，而非显式靠近 X7 的策略。"

**严重度**：低。<br>
**是否影响预注册判定**：否。<br>
**建议**：补充上述因果说明。

### R7-C04：解读第 3 点"外推本身就很稳"未充分限定外推的几何结构

**问题**：解读称"Steinmetz 型 log 线性均值 + GP 在 f–B 方向的外推本身就很稳"。但 X7（f ≥ 200 kHz ∧ Bpk ≥ 0.10 T）是二维空间的一个角落。池中仍有：
- f ≥ 200 kHz、Bpk < 0.10 T 的点（同频、低幅）；
- f < 200 kHz、Bpk ≥ 0.10 T 的点（低频、同幅）。

因此模型不是"从零外推到角落"，而是"从两条边沿内推到角落"——这是比纯外推更温和的情况。iGSE 18.2% vs 代理 1.5–2.0% 的对比固然成立，但"外推很稳"的结论应明确说明这是**L 形边界向角落的内推**，而非更一般的"到任意未知区域的外推"。

**严重度**：低。<br>
**是否影响预注册判定**：否——这是解读措辞，不是判据问题。<br>
**建议**：加一句限定："X7 是高频–高幅角落，池中保留了同频低幅与低频同幅的数据，模型本质上在做 L 形边界的角落内推，而非无支撑的外推。"
